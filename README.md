## ✨ Возможности

- 🎯 **Автоматический поиск видео** — расширение само находит поток
- 📥 **Лучшее качество** — загружается самый качественный вариант
- 🎞️ **MP4 без потери качества** — видео перепаковывается без перекодирования
- 📝 **Понятные имена файлов** — название берётся со страницы
- 🎨 **Встроенная кнопка** — стоит рядом с «Нравится» и выглядит как родная
- 📊 **Индикатор прогресса** — с возможностью отмены
- ⚡ **Быстрая загрузка** — сегменты скачиваются параллельно

## 🚀 Установка

1. Скачайте проект: `git clone https://github.com/hOvannes7/Antonov-Downloader.git` (или **Code → Download ZIP** на GitHub и распакуйте)
2. Откройте `chrome://extensions/`
3. Включите **Режим разработчика** (справа вверху)
4. Нажмите **Загрузить распакованное** и выберите папку проекта

## 📖 Использование

1. Откройте видео на [antonov.media](https://www.antonov.media)
2. Дождитесь загрузки плеера
3. Нажмите **⬇ Скачать** слева от кнопки «Нравится»
4. Файл сохранится в формате `.mp4`

## 🛠️ Если что-то не так

| Проблема | Решение |
|----------|---------|
| Кнопка не появляется | Дождитесь загрузки плеера или обновите страницу |
| «Видео не найдено» | Запустите воспроизведение и нажмите кнопку ещё раз |
| «Поток зашифрован» | Зашифрованные потоки (`#EXT-X-KEY`) не поддерживаются |
| Ошибка при загрузке | Одна из частей видео не скачалась — повторите попытку |
| Сохранился `.ts`, а не `.mp4` | Поток нестандартный (например, HEVC) и не перепаковывается. Файл воспроизводится в VLC, а конвертируется командой `ffmpeg -i video.ts -c copy video.mp4` |

Для отладки поставьте `DEBUG = true` в начале `content.js` и откройте консоль на странице видео.
