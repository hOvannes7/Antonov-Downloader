# Antonov Downloader

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Chrome extension для скачивания видео с antonov.media**

---

**[🇬🇧 English version](README.en.md)**

## 📌 Описание

Antonov Downloader — это расширение для браузера Google Chrome, которое позволяет скачивать видео с сайта [antonov.media](https://www.antonov.media). Расширение находит HLS-поток (`.m3u8`), загружает все сегменты и собирает их в один файл `.mp4`.

## ✨ Возможности

- 🎯 **Автоматическое обнаружение видео** — расширение само находит видеопоток
- 📥 **Скачивание в высоком качестве** — загружается лучший доступный поток
- 📝 **Именованные файлы** — название видео берётся со страницы
- 🎨 **Интеграция в интерфейс** — кнопка скачивания рядом с кнопкой «Нравится»
- 📊 **Индикатор прогресса** — отображается внизу страницы
- ⚡ **Быстрая загрузка** — сегменты загружаются параллельно
- 🎞️ **MP4 без потери качества** — видео перепаковывается без перекодирования
- 🔄 **Работает при переходах между видео** — без перезагрузки страницы

## 🚀 Установка

### Из репозитория

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/hOvannes7/antonov-downloader.git
   cd antonov-downloader
   ```

2. Откройте Chrome и перейдите на `chrome://extensions/`

3. Включите **Режим разработчика** (переключатель в правом верхнем углу)

4. Нажмите **Загрузить распакованное**

5. Выберите папку `antonov-downloader` (ту, где лежит `manifest.json`)

## 📖 Использование

1. Откройте любое видео на `www.antonov.media/watch*` (переходы между видео без перезагрузки страницы тоже поддерживаются)
2. Дождитесь загрузки видеоплеера
3. Слева от кнопки «Нравится» появится кнопка **⬇ Скачать**
4. Нажмите кнопку — начнётся скачивание, в конце файл сохранится в формате `.mp4`
5. Дождитесь завершения загрузки

## ⚠️ Важная информация

- Видео сохраняется в формате `.mp4`: сегменты MPEG-TS (H.264 + AAC) перепаковываются в MP4 прямо в браузере, **без перекодирования** — качество не меняется
- Если поток нестандартный (например, HEVC или AC-3 звук), перепаковка не выполняется, и файл сохраняется как `.ts` — об этом будет написано в индикаторе
- Файл `.ts` воспроизводится в большинстве плееров (VLC, MPC-HC, PotPlayer), а при необходимости конвертируется вручную:
  ```bash
  ffmpeg -i video.ts -c copy video.mp4
  ```
- Чтобы всегда сохранять «сырой» `.ts`, поставьте `OUTPUT_MP4 = false` в начале `content.js`

## 🛠️ Возможные проблемы

| Проблема | Решение |
|----------|---------|
| Кнопка не появляется | Дождитесь загрузки плеера; если не помогло — обновите страницу |
| Видео не найдено | Запустите воспроизведение и повторите; проверьте в DevTools → Network загрузку `.m3u8` |
| Поток зашифрован | Зашифрованные HLS-потоки (`#EXT-X-KEY`) не поддерживаются |
| Файл не скачивается | Одна из частей видео не загрузилась — повторите попытку (текст ошибки виден в индикаторе) |
| Ошибка CORS | Некоторые видео могут требовать авторизацию |

## 📝 Примечания

- Если сайт использует DRM-защиту — скачивание невозможно
- Некоторые видео могут требовать cookie/авторизацию
- Для отладки поставьте `DEBUG = true` в начале `content.js` и откройте консоль на странице видео
