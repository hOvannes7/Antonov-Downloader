Спасибо за интерес к проекту! Мы приветствуем вклад в развитие расширения.

## 📋 Как помочь

### Сообщить об ошибке

1. Проверьте существующие [Issues](https://github.com/hOvannes7/antonov-downloader/issues)
2. Если ошибка не найдена, создайте новый Issue
3. Опишите проблему подробно:
   - Что произошло?
   - Что ожидали?
   - Шаги воспроизведения
   - Версия Chrome

### Предложить функцию

1. Создайте Issue с описанием идеи
2. Объясните, какую проблему это решает
3. Обсудите перед началом работы

### Внести код

```bash
# Форкните репозиторий
git clone https://github.com/hOvannes7/antonov-downloader.git
cd antonov-downloader

# Создайте ветку
git checkout -b feature/my-feature

# Внесите изменения и закоммитьте
git commit -m "Добавлена новая функция"
git push origin feature/my-feature
```

3. Создайте Pull Request на GitHub
4. Опишите, что изменилось и зачем
