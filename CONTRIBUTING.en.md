**[🇷🇺 Русская версия](CONTRIBUTING.md)**

---

Thank you for your interest in the project! We welcome contributions to the extension.

## 📋 How to Help

### Report a Bug

1. Check existing [Issues](https://github.com/hOvannes7/antonov-downloader/issues)
2. If not found, create a new Issue
3. Describe the problem in detail:
   - What happened?
   - What did you expect?
   - Steps to reproduce
   - Chrome version

### Suggest a Feature

1. Create an Issue with your idea
2. Explain what problem it solves
3. Discuss before starting work

### Contribute Code

```bash
# Fork the repository
git clone https://github.com/hOvannes7/antonov-downloader.git
cd antonov-downloader

# Create a branch
git checkout -b feature/my-feature

# Make changes and commit
git commit -m "Added new feature"
git push origin feature/my-feature
```

3. Create a Pull Request on GitHub
4. Describe what changed and why
